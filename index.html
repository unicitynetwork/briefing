Astrid11 PRs merged
CI/CD pipeline hardening and automation overhaul
A cluster of CI-focused PRs reshaped how the codewall pipeline runs and self-maintains. #64 introduced issue forms, a Claude-powered auto-fix workflow, and automatic reopen-for-testing on merge, while #66 pinned Claude to Opus 5.5 for consistent autofix behavior and #67 enforced Codewall policy directly on Claude Code prompts. #65 switched the build to consume a pinned Astrid builder instead of compiling Astrid from source, cutting build time and variance. Together these changes make the CI loop faster, more deterministic, and self-healing.
codewall
Installer security and reliability fixes
Several PRs tightened up installer robustness and safety. #61 ensures the publish gate and managed settings are readable under a strict umask 077, closing a permissions gap. #69 bounds runtime subprocess waits to prevent the installer from hanging indefinitely, and #70 adds test coverage for picker cancellation flows and Windows terminal edge cases. These changes reduce installer failure modes across platforms and harden it against misconfigured environments.
codewall
TLS capsule config caching for protocol layer
#68 caches the protocol capsule's TLS configuration instead of recomputing it repeatedly, reducing overhead on the hot path for TLS-secured protocol operations. This is a targeted performance fix that avoids redundant configuration work during capsule setup.
codewall
Routine dependency upgrades
Dependabot delivered three maintenance bumps: clap 4.6.6→4.6.7 (#54), hkdf 0.12.4→0.13.0 (#51), and actions/checkout 4→7 (#50). These keep the CLI argument parser, key derivation crate, and CI checkout action current with upstream security and compatibility fixes.
