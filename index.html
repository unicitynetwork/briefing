Astrid2 PRs merged
Hook forwarding restored across codex and frontend layers
PRs #33 and #83, both authored by @joshuajbouw, repair hook propagation at two distinct integration points. In #33 the codex oracle layer was updated to correctly forward response payloads and fire session-end hooks rather than dropping them. PR #83 addresses the complementary problem in aos-ce, ensuring that frontend response events are preserved through the hook chain instead of being silently discarded. Together these fixes close a gap where downstream consumers of hook events could receive incomplete or missing lifecycle signals, restoring reliable event-driven behaviour across the AOS stack.
unicity-aos, aos-ce
Sphere5 PRs merged
Token engine rate-limit retry and 20-wide certification
PR #747 introduces two related performance improvements to the token engine: automatic retry logic when a submit call is rate-limited by the network, and the ability to certify batches 20 tokens wide in a single operation, significantly increasing throughput. PR #748 then addresses three concrete review findings raised against #745 and #747, tightening correctness issues identified in code review before the changes were considered stable. These PRs collectively make the token engine more resilient under load and more efficient for high-volume certification workflows.
unicity-sphere/sphere-sdk
Payments-v2 resume now shares send-path settlement logic
PR #745 fixes a behavioural inconsistency in the payments-v2 module where a resumed payment session was making its own independent settlement decision rather than reusing the same decision path followed by the initial send. This divergence could cause a resumed session to settle differently from what the send path would have chosen, introducing subtle correctness bugs in payment flows that span interruptions. Aligning the two paths under a single settlement decision function ensures consistency and reduces the surface area for future divergence.
unicity-sphere/sphere-sdk
SDK bump to 0.14.5 and stale comment cleanup
PR #484 updates the sphere application to consume sphere-sdk version 0.14.5, pulling in the token-engine and payments-v2 fixes landed in #745, #747, and #748. PR #743 removes a now-orphaned code comment that referenced a function deleted in #742, eliminating misleading documentation that could have confused future contributors. These housekeeping changes keep the repository in a clean, consistent state following the substantive feature and fix work earlier in the cycle.
unicity-sphere/sphere, unicity-sphere/sphere-sdk
