AOS Audit Capsule Goes Live
PR #1 introduces the foundational AOS capsule with key lifecycle management, operations, and per-entry receipts, establishing the core audit trail architecture. PR #2 builds on this by optimizing the anchoring loop to write runtime state only on change, reducing unnecessary I/O and improving efficiency. Together these PRs by @MastaP lay the groundwork for a durable, low-overhead audit system. This marks the initial buildout of the aos-audit repo's core functionality.

All three PRs by @jvsteiner focus on hardening both security posture and CI stability for codewall.

Bridged Token Vaults Enforce Lock or Split
PR #7 introduces a requirement that every bridged token type must specify either a lock or split reason, adding explicit accounting for token state transitions. Additionally, replaced vaults are now restricted to verify-only mode, preventing further mutation once superseded. This change by @lploom strengthens the integrity guarantees of the bridge's vault lifecycle and reduces ambiguity in cross-chain token handling. It's a key correctness improvement for the bridge's security model.
