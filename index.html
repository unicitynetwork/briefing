Codex Now Connects via Persistent Gateway
PR #40 replaces the ad-hoc 'mcp serve' invocation with a persistent gateway connection for Codex attachment. This removes the overhead of spinning up a fresh MCP server process for each session, improving reliability and startup latency. The persistent gateway pattern also lays groundwork for sharing a single connection across multiple oracle clients. Authored by @joshuajbouw.

Sphere1 PRs merged
SDK Changelog Gets Versioned Sections
PR #758 documents the 0.14.11 release and restructures the changelog into versioned sections going forward. This makes it easier for downstream consumers to track breaking changes and fixes per release rather than scrolling a flat history. The change is purely documentation but establishes a maintainable pattern for future SDK releases. Authored by @MastaP.

Unicity Network4 PRs merged
State-Transition SDKs Reach TypeScript-Java Parity
PR #151 splits the inclusion proof response from the underlying proof object in the JS SDK, giving callers cleaner access to metadata versus cryptographic proof data. PR #150 moves transfer decoding into the worker thread instead of extracting a single field on the main thread, reducing main-thread blocking and centralizing parsing logic. PR #84 brings the Java SDK's wire format and API up to parity with TypeScript SDK 3.0.1, closing a cross-language compatibility gap. Together these changes ensure both SDKs speak the same protocol version with consistent proof handling. Authored by @MastaP.
state-transition-sdk-js, state-transition-sdk-java
Java SDK Enforces Request Timeouts
PR #83 binds service time tracking and enforces request timeouts in the Java SDK, preventing hung requests from blocking callers indefinitely. This adds resilience for production deployments where network or server latency spikes could otherwise cause cascading delays. The timeout enforcement complements the wire-format parity work in PR #84 to make the Java SDK production-ready alongside its TypeScript counterpart. Authored by @ristik.
