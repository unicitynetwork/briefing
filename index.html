2026.9.1 hotfix shipped across AOS stack
The team coordinated a synchronized hotfix release across three repos: aos-ce #163 and oracles #63 prepared the 2026.9.1 release artifacts, while unicity-aos.github.io #17 updated the installer site to serve the newly published installers. This ensures users pulling install scripts get the patched binaries immediately rather than a stale prior version. The release closely follows oracles #61, which fixed a startup regression, suggesting this hotfix exists specifically to get that fix into users' hands fast.
unicity-aos.github.io, aos-ce, oracles
Oracle host no longer blocks on MCP setup failures
PR #61 fixes an oracle startup bug where MCP (Model Context Protocol) setup issues would hang or block the host process instead of just being reported. Now setup failures are logged/reported without preventing the oracle host from starting, improving resilience for operators running oracle nodes. This was significant enough to warrant its own 2026.9.1 hotfix (#63) to get the fix out quickly.

Gateway unreachable errors surface instead of silent hangs
PR #516 improves subscription handling by explicitly reporting when the gateway is unreachable rather than letting the client hang silently with no feedback. This directly improves debuggability and user experience for anyone relying on subscription features, since silent hangs are hard to diagnose. The fix by @KruGoL turns an ambiguous failure mode into an actionable error message.
