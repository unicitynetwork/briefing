Astrid2 PRs merged
Unified severity and alerting model for codewall
PR #16 establishes operator notifications as their own distinct surface rather than folding them into the existing alert taxonomy, clarifying ownership and routing semantics. PR #15 defines a single severity scale with five canonical values that must remain consistent from the data store through the wire protocol to the feed consumers. Together these changes reduce ambiguity in how severity is represented and interpreted across the pipeline. This groundwork by @lploom sets up cleaner downstream consumption for both alerting and notification surfaces.
unicity-aos/codewall-design
Sphere2 PRs merged
Parallelized §8.2 decode and verify pipeline
PR #126 moves §8.2 decode+verify validation onto a blob-level worker pool, enabling concurrent processing instead of serial handling of validation blobs. PR #32 complements this by making the verify worker pool size and deposit concurrency configurable via sphere-infra parameters. Together these changes let operators tune throughput based on deployment load rather than relying on fixed concurrency limits. This should meaningfully improve validation performance under high deposit volume, authored by @MastaP across both repos.
unicity-sphere/sphere-infra, unicity-sphere/wallet-api
Unicity Network3 PRs merged
Severity scale extended into semanticd's rule pipeline
PR #147 extends the same five-value severity scale work from codewall into semanticd, ensuring consistency from rule definition through table storage, wire transmission, and feed output. This mirrors the astrid-side severity work by @lploom, aligning the two systems on one canonical severity model. Keeping the scale identical across services avoids translation bugs and simplifies cross-system alert correlation.
unicitynetwork/semanticd
Rulesets get first-class dashboard tab
PR #146 promotes rulesets to their own dashboard tab and simplifies the console's status language down to a single word, improving operator clarity. This UI change by @jvsteiner makes ruleset management more discoverable and reduces cognitive overhead when scanning dashboard state.
unicitynetwork/semanticd
Hardened JWT signing and session binding
PR #145 strengthens authentication by hardening JWT signing and tightening session binding, closing potential gaps in token integrity and session hijacking vectors. This security fix from @jait91 reduces risk in the auth layer that other semanticd features depend on.
