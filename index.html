Payments V2: Real-Time Multi-Token Progress Reporting
PR #749 in sphere-sdk extends the payments-v2 pipeline to report each certified leg individually as it completes, so that multi-token send operations surface genuine incremental progress rather than a single final callback. A2A Capsule Binding Events Now Publish Chain Pubkey
PR #1 in a2a-capsule fixes a bug in core binding-event publication where the chain public key was omitted from emitted events, rendering nametag-addressed capsules unpayable by external parties. Without the chain pubkey in the binding event, resolvers had no cryptographic anchor to validate the nametag-to-address mapping and would silently drop payment attempts. The fix ensures every binding event carries the full chain pubkey so nametag resolution completes correctly end-to-end. This is a critical correctness fix for any workflow relying on human-readable nametag addressing.
a2a-capsule
Policy Versions Moved to Shared Band for SIF Compatibility
PR #113 in semanticd corrects a database schema placement issue where the policy_versions table was scoped to an isolated band rather than the shared band, causing the Semantic Interpretation Framework to fail silently when attempting to load policies at startup. The shared band is the authoritative data partition accessible across all SIF instances, so any table outside it is invisible to cross-instance queries. Moving policy_versions into the shared band restores full policy-loading capability without requiring schema migrations on individual instance bands. This fix unblocks deployments where SIF policy enforcement was completely non-functional.
semanticd
