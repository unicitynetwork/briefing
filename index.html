Oracle hooks gain full native event coverage
PR #208 expands canonical Oracle events and adds policy routing, while PR #82 registers complete native client event coverage in the oracles package. PR #83 then prepares the Oracle 2026.10.0 release to ship these hook improvements. Together these changes give downstream consumers a richer, more reliable event surface for building policy-aware integrations. This is foundational work for anything that needs to react to Oracle state changes in real time.
aos-ce, oracles
Streaming and discovery reliability fixes
PR #209 batches fast provider text responses and rejects stale turn replies, fixing race conditions in the streaming pipeline. PR #213 ensures delayed MCP providers are still collected before the discovery deadline expires, preventing dropped providers under load. PR #211 fixes CLI workspace selection so principal discovery targets the correct product workspace. PR #216 preserves native filesystem support across later runtime versions, closing a regression gap. Collectively these patches harden core AOS-CE request handling and runtime compatibility.
aos-ce
Codewall storage leak from heartbeats fixed
PR #107 fixes idle storage growth caused by producer heartbeats accumulating unused state. This prevents unbounded resource consumption in long-running idle deployments. The fix improves operational stability for services relying on codewall's heartbeat mechanism.
codewall
