Astrid1 PRs merged
AOS Community Edition gets official open-source license
PR #79 introduces the formal license for the AOS Community Edition, establishing the legal framework under which the open-source variant of AOS is distributed. This is a foundational governance step that defines usage rights, redistribution terms, and contributor obligations for the CE build. Without this, downstream adopters and integrators had no clear licensing baseline to build on. The change positions AOS CE for broader community adoption and third-party packaging.
unicity-aos
Sphere2 PRs merged
Payments module hardened and restructured for reliability
Two back-to-back PRs from @MastaP overhaul the payments subsystem in sphere-sdk. PR #726 fixes a critical race condition where an incoming token could be silently dropped because the code awaited only the first load future rather than the current one — any token received mid-flight would be lost. PR #723 is a breaking refactor that splits the previously monolithic payments module into per-feature files and removes dead ceremony code, reducing coupling and improving navigability. Together these changes make the payment flow both more correct and more maintainable, and the breaking label signals that downstream integrators should review their import paths.
unicity-sphere
Unicity Network2 PRs merged
SIF dashboard tokens stay alive; SMT gains prefix-major layout
PR #87 in semanticd fixes a hotfix-grade session management bug where SIF dashboard access tokens were expiring after a hard-coded 15-minute window instead of being refreshed, effectively logging out users or breaking automated dashboard sessions. The fix replaces expiry logic with a proper token-refresh flow, restoring continuity for long-running sessions. Separately, PR #173 in aggregator-go introduces a prefix-major disk layout for the Sparse Merkle Tree, organising on-disk SMT nodes by key prefix at the top level rather than a flat structure. This layout improves read locality and sets the groundwork for more efficient range queries and partial-tree loads as the aggregator scales.
semanticd, aggregator-go
