Astrid12 PRs merged
Standalone daemon recovery and custody stall fixes
PR #132 shares runtime readiness state and auto-starts stopped standalone Astrid daemons, while #131 fixes custody stall recovery and the preflight checks for standalone public installs. PR #228 refuses to proceed with a stopped setup before device keys are created, preventing a broken install state. Together these close gaps where standalone AOS instances could get stuck mid-setup or fail silently on custody operations. This reduces support burden around first-run and recovery flows.
codewall, aos-ce
Authenticated consent binding across MCP and install flows
A cluster of fixes (#92, #91, #227, #130) harden how native consent and credentials are bound during MCP attach and public installation. #91 routes MCP attach through authenticated AOS consent, #227 preserves native consent when attaching via a shared gateway, and #92 provisions an authenticated native hook adapter binding. #130 fixes public installation readiness and bridge credential binding so installs don't complete with stale or unauthenticated bindings. These changes close consent-bypass and credential-mismatch risks in multi-process AOS deployments.
oracles, aos-ce, codewall
BLAKE3 checksums and capsule identity authentication
PR #223 adds bundled BLAKE3 file checksums to the install artifacts, and #89 builds on this to authenticate capsule identities using those bundled AOS checksums. This establishes a verifiable integrity chain from install bundle to runtime capsule identity, reducing the risk of tampered or mismatched builds being accepted. It's a foundational security step for the install pipeline.
oracles, aos-ce
CI pipeline and October release stabilization
PR #128 aligns CI fixtures, the custody probe, and E2E bootstrap so test runs are consistent; #127 automates moving awaiting-testing issues to In Test on SIF. PR #226 binds the October dev candidate to Astrid rc.3, locking in the release baseline ahead of testing. These changes keep the CI/release process synchronized with the feature work landing elsewhere in the sprint.
codewall, aos-ce

Jailbreak detection expanded to 13 languages
PR #453 unlocks jailbreak detection across 13 languages, building on #448's earlier work to unlock jailbreaks in every training language. PR #454 adds training data for the 'From now on, you are an unfiltered assistant' jailbreak family, and #461/#462 fix mislabeled jailbreak-payload injections, retraining the model after relabelling. This significantly widens jailbreak coverage beyond English-only detection and corrects a labeling bug that was letting payload-bearing injections slip through as non-jailbreak.
semanticd
Multilingual PII detection for locations and birth dates
PRs #451, #455, and #459 build out DLP NER labels, training data, and a retrained model for detecting locations and dates of birth across multiple languages. PR #460 refines Cyrillic look-alike folding so it only normalizes characters when they're disguising Latin text, avoiding false positives in genuine Cyrillic content. This expands the semanticd DLP detector's entity coverage and improves precision for script-mixing evasion attempts.
semanticd
Prompt injection training hardened against benign role-play
PR #456 adds composed greetings and sign-offs to prompt injection training, #446 adds multilingual short benign messages, and #444/#450 push further on composed greetings in benign data while using QA's still-blocking list as a promotion gate. These changes specifically target false positives where legitimate conversational patterns (greetings, sign-offs, short benign chat) were being misclassified, tightening the precision/recall balance of the prompt_injection model before promotion.
semanticd
Policy engine, threshold calibration, and gateway reliability
PR #452 fixes policy evaluation so a policy with no ruleset still runs the detectors it names, and #445 calibrates ML thresholds for unconfigured policies with per-probe startup checks. PR #457 fixes gateway timeouts, receipt metrics, and ACK replay issues along with test cleanup, improving runtime reliability. PR #447 automates CI issue triage (awaiting-testing to In Test), and #436 is a dependabot bump of source-map-js for a security advisory. Together these harden the operational core of semanticd outside the ML model work.
