Sphere2 PRs merged
WalletConnect-powered Sepolia USDC bridge signing
Sphere now supports signing Sepolia USDC bridge-ins and collects using a mobile wallet app via WalletConnect, implemented in sphere#549. To support this, sphere-infra#54 wires the WalletConnect project ID through to the Sphere containers as configuration. Together these PRs let users approve bridge transactions from their phone instead of a hot wallet embedded in the app. This improves custody and security posture for bridge operations.
sphere-infra, sphere
Unicity Network17 PRs merged
Bridge service resilience: graceful drains and failure handling
Several PRs harden the bridge-out and return services against abrupt termination and transient failures. unicity-bridge#37 and bft-ansible#48/#47 make the bridge-out service drain in-flight work on SIGTERM instead of abandoning proofs mid-flight. unicity-bridge#34 makes the return service tolerate a failed chain-log read rather than failing an already-proven batch. These changes reduce lost work and inconsistent state during deploys or restarts on testnet2.
unicity-bridge, bft-ansible
WalletConnect signing and chain-id hardening for EVM bridge
unicity-bridge#36 adds support for Ethereum wallet apps to sign bridge transactions through WalletConnect, mirroring the Sphere-side integration. It also makes EVM signers read a numeric chain id and enforce timeouts, improving correctness and robustness against hanging RPC calls. unicity-bridge#38 adds CI so pull requests run tests and the service image is built from main, tightening the delivery pipeline for these changes.
unicity-bridge
Testnet2 bridge observability, alerting, and backups
A cluster of ansible changes builds out operational maturity for the testnet2 bridge: bft-ansible#46 adds alerts for chain-log outages separate from batch failures, #44 escalates prover crashes and failed batches to critical alerts, and #43 sizes /dev/shm to 8g with 10 retry attempts plus alerts for hung proofs. bft-ansible#45 copies the bridge journal off-box to S3 hourly, backed by a new private S3 bucket provisioned in bft-terraform#30. bft-ansible#42 pins local compose versions for bft-core, aggregator-go, and gateway. Together these give operators faster detection of failures and durable backups of bridge state.
bft-ansible, bft-terraform
Wallet and library hygiene fixes
webwallet#9 removes key material from logs, adds a consent step before debug reports, and fixes a broken Stop Scan control, closing several security and UX gaps. webwallet#10 stops tracking wallet .dat files in git. proof-cli#15 cleans up the library's public surface so it only exports what's intended rather than shipping internals by accident. semanticd#533 and #534 fix training host-setup's uv steps and apply policy settings to Codewall central alerts, respectively.
webwallet, proof-cli, semanticd
