Codewall Audit Trail Goes Durable and Custodied
PR #71 recorded fail-closed enforcement errors in telemetry, and PR #72 built on that to add durable capture and custody for audit events. PR #73 landed the audit reliability work (from #72) onto main, and companion design doc #19 catalogs the telemetry error codes the plane emits so downstream consumers can handle them consistently. Together these PRs make Codewall's audit pipeline resilient to crashes and give a clear contract for error reporting.
codewall, codewall-design
macOS Release Tooling and Test Stability
PR #74 adds local make targets to build, sign, notarize, and publish macOS releases, reducing reliance on CI for release cutting. PR #75 removes Linux fork races from installer tests, fixing flaky test failures tied to process forking on Linux runners. Both changes tighten the release and testing infrastructure around the installer without touching product behavior.
codewall

Wallet API Alerting Accuracy Improvements
PR #48 fixes the ELB 5xx alarm so it only counts service-side ELB error codes, cutting down false positives from client-side errors. PR #46 corrects Grafana documentation, clarifying that wallet-api actually has 24 alert rules, not 21. These changes improve confidence in on-call alerting accuracy for wallet-api.

Bot Traffic Migrates Off Wallet API
PR #47 tracks agentic-chatbot commit c51be42, which stops messaging bots from calling wallet-api directly. This reduces load and coupling between the chatbot system and wallet-api, likely simplifying capacity planning and alert tuning for the service.
