Astrid8 PRs merged
AOS 2026.9.3 release and signing pipeline hardened
PR #192 prepares the AOS 2026.9.3 release, backed by three fixes that make the release pipeline trustworthy. PR #197 resolves Command Center code signing by using a temporary keychain instead of relying on the login keychain, avoiding CI signing failures. PR #196 fixes notarization to properly use Apple ID credentials so shipped binaries clear Gatekeeper. PR #195 bounds default musl compiler parallelism to prevent runaway build resource usage during compilation. Together these changes make the release process reproducible and less fragile across CI runs.
aos-ce
Oracle discovery and update checks fixed
Three PRs fix how AOS discovers and verifies available Oracle releases. PR #19 corrects Oracle release resolution on the public install website, and PR #73 mirrors that fix so the installer defaults to the latest published Oracle rather than a stale one. PR #198 hardens the update mechanism by adding an authenticated read-only channel check before pulling updates, closing a gap where unauthenticated checks could be spoofed. These changes ensure users installing or updating AOS always get the correct, verified release.
unicity-aos.github.io, oracles, aos-ce
Plugin session notices no longer block UI
PR #72 restores nonblocking session update notices in the plugin system, fixing a regression where notices could freeze or stall the interface. This ensures session-related notifications surface without interrupting normal plugin operation, improving day-to-day usability for Oracle operators.

Wallet safety fixes for import and listing
PR #808 fixes a critical bug where importing a wallet could silently erase an existing one, addressing a data-loss risk flagged in issue #801. PR #813 fixes listWallets in the Node.js bindings so it no longer hides a wallet or incorrectly lists a backup file as an active wallet. Both changes protect users from losing access to or visibility into their wallets, a core reliability guarantee for the SDK. These are user-facing correctness fixes rather than cosmetic changes.
